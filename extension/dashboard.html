Import sent history

From the old “LinkedIn Automated Reachout” extension, so nobody it already sent a request to gets a second one. Do this once, before your first run.

How to get the file from the old extension
  1. Click the old extension's icon → Upload CSV (this opens its page).
  2. Press F12 (Mac: Cmd+Option+I) → Console, paste this line and press Enter. It downloads outreach-sent-history.json:
chrome.storage.local.get(null, d => { const h = {}; for (const k in d) if (k.startsWith("h:")) h[k] = d[k]; const a = document.createElement("a"); a.href = URL.createObjectURL(new Blob([JSON.stringify(h)], { type: "application/json" })); a.download = "outreach-sent-history.json"; a.click(); console.log(Object.keys(h).length + " people"); });

The old extension's Export CSV file works too (rows whose requestStatus is “Sent”).
